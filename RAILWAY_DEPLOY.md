# Railway Deployment Guide

## 1. Crear Proyecto en Railway
```
railway login
railway init
```

## 2. Crear PostgreSQL Plugin
```
railway add --name postgres
```

## 3. Configurar Variables de Entorno
```
railway variables set DATABASE_URL postgresql://...
railway variables set GITHUB_TOKEN github_pat_...
railway variables set ANTHROPIC_API_KEY sk-ant-...
railway variables set OPENAI_API_KEY sk-...
railway variables set JWT_SECRET your-secret-key
railway variables set NODE_ENV production
```

## 4. Deploy
```
cd backend
railway up
```

## 5. Test
```
curl https://your-railway-app.railway.app/health
```

## 6. Autonomous Commits
Una vez deployado, el Architect puede hacer commits llamando:
```
POST https://your-railway-app.railway.app/api/deploy/commit
Content-Type: application/json

{
  "message": "feat: generated by Architect",
  "files": {
    "path/file.ts": "code here"
  }
}
```

---

**El sistema es completamente autónomo después de esto.**
